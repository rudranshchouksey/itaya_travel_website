# Itvaya Travel Website

This repository contains the frontend web application for Itvaya Travel, built with Next.js, React, and Tailwind CSS.

## Technology Stack
- Next.js (App Router)
- React
- Tailwind CSS
- TypeScript

## Setup
\`\`\`bash
npm install
\`\`\`

## Run Locally
\`\`\`bash
npm run dev
\`\`\`
